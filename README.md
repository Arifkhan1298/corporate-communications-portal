# CORVANTA — Corporate Communications Portal

> *"Connect People. Align Teams. Move Business Forward."*

A world-class, ultra-premium, production-grade **Corporate Communications Portal** engineered for modern multinational enterprises, executive leadership, cross-functional teams, and portfolio demonstrations.

---

## 💎 Executive Overview

**CORVANTA** centralizes organizational transparency, executive communications, multi-channel broadcast campaigns, internal messaging, department health analytics, employee directories, and crisis communications into a unified, high-speed workspace.

Designed with an executive aesthetic combining **Deep Emerald Forest Green**, **Warm Champagne Gold**, and **Obsidian Graphite**, the platform provides an instantaneous, fluid experience with zero loading friction.

---

## 🚨 Strict Architecture & File Structure

This repository strictly adheres to the **Absolute Zero-Folder Rule**:

```text
Corporate Communications Portal/
├── index.html        # Semantic HTML5, accessible SVGs, responsive application shell & modals
├── style.css         # Deep emerald + warm champagne gold design system, glassmorphism, responsive grid
├── script.js         # Reactive state engine, local database, messaging, calendar, canvas charts, search
└── README.md         # Enterprise product documentation, architecture overview, and usage guide
```

- **0 Subdirectories / 0 Folders**: All assets, stylesheets, scripts, and document templates reside directly in the root directory.
- **Zero Build Tools or CDNs**: 100% offline-capable with native system fonts, inline SVGs, and responsive HTML5 Canvas charts.
- **Instant Launch**: Simply open `index.html` in any modern web browser.

## ⚡ Core Feature Inventory

### 1. Authentication & Instant Demo Workspace
- **SSO Simulation**: Work email and password authentication with local session validation.
- **Instant Access Bypass**: Single-click `"Enter Demo Workspace"` button for rapid review and portfolio walkthroughs.

### 2. Executive Overview & Dynamic KPIs
- **Date Range Filters**: `Today`, `7 Days`, `30 Days`, and `90 Days` dynamic calculation.
- **8 Core Metrics**:
  1. *Active Employees* (2,846)
  2. *Announcements* (128)
  3. *Messages Sent* (18,492)
  4. *Communication Reach* (94.8%)
  5. *Unread Updates* (326)
  6. *Active Campaigns* (14)
  7. *Employee Engagement* (87%)
  8. *Feedback Score* (92%)
- **Custom HTML5 Canvas Charts**: Dual-metric Reach & Engagement trend line/area visualization and channel distribution donut chart.
- **Executive Spotlight**: Featured keynote address from Chief Executive Officer Elena Sterling with direct reader modal.

### 3. Corporate Announcements Engine
- Multi-dimensional filtering by Category (*Company News, Executive Update, HR, Finance, Technology, Operations, Culture, Security, Events*), Priority (*Normal, Important, Urgent*), and Lifecycle Status (*Draft, Scheduled, Published, Archived*).
- Complete CRUD workflow: **Create, Edit, Preview Modal, Publish, Schedule, Archive, and Delete**.

### 4. Internal Corporate Messaging
- Split-panel communications interface with persistent conversation threads:
  - *Elena Sterling (CEO)*
  - *Marcus Chen (Global HR Director)*
  - *Marketing & Comms Core (Group)*
  - *Engineering & Infrastructure (Group)*
  - *Sophia Reyes (CFO)*
  - *Operations Command Center*
- Real-time message composer with emoji reaction simulation, attachment buttons, and automated interactive responses.

### 5. Corporate Newsroom
- Curated public relations stories, international milestones, and business award recognitions.
- Instant category filtering, reading time estimates, full article modal reader, and clipboard sharing.

### 6. Department Operations & Employee Directory
- 10 organizational units (*Executive, Marketing, Engineering, Finance, HR, Sales, Operations, Customer Success, IT, Legal*) with live communication health scores and roster counts.
- Searchable roster of international team members with department filters, availability status indicators, skill tags, direct email links, and profile modals.

### 7. Communication Campaigns
- Strategic campaign management tracking channels (*Internal Portal, Email, Announcement, Messaging, Push Notification*), start/end dates, open rates, and progress bars.
- Controls to **Pause, Resume, Duplicate, and Delete** campaigns.

### 8. Communication Calendar & Events
- Interactive Month Grid and Agenda List views.
- Interactive day clicking with instant event scheduling.
- Corporate Town Halls and Leadership Summits with one-click **RSVP Registration toggle**.

### 9. Document Center
- Enterprise policy vault and document repository with file format badges (*PDF, XLSX, DOCX*).
- **Client-Side File Generation**: Direct browser download of authentic formatted `.txt` and `.csv` audit blobs using `URL.createObjectURL`.

### 10. Feedback & Task Management
- Two-way employee feedback center (*Suggestion, Complaint, Idea, Recognition, Question*) with manager status progression (*New, Under Review, In Progress, Resolved*).
- Drag-and-drop / single-click task movement across a 4-column Kanban board (*To Do, In Progress, Under Review, Completed*).

### 11. Communication Analytics & Executive Reports
- Deep-dive departmental communication volume bar charts and area graphs.
- Downloadable compliance CSV reports.

### 12. Global Search System
- Universal shortcut (`Ctrl + K`) triggering a fast, live search indexing announcements, employees, departments, campaigns, documents, and events.

## 🚀 Quick Start Guide

1. Clone or download this project folder to your local computer.
2. Double-click or open `index.html` in any web browser (Chrome, Edge, Safari, Firefox).
3. Click **"Enter Demo Workspace (Instant Access)"** to immediately enter the executive portal.
4. Test any feature: publish an announcement, send a message to the CEO, schedule an event, filter employees, or download a document!

---

## 🔒 Data Persistence & LocalStorage

All changes made during your session (new announcements, drafted messages, completed tasks, submitted feedback, and appearance preferences) are automatically synchronized with `localStorage` under the key `corvanta_store_v1`. 

To reset the portal back to its default state at any time, navigate to **Settings** → click **"Reset Demo Data"**.
